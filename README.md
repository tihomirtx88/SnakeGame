# Змия · Snake Game

Браузърна игра на български, без външни библиотеки и без инсталиране на зависимости.

## Стартиране

Отвори `index.html` в съвременен браузър или стартирай локален сървър от папката на проекта:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

При локално стартиране на твоя компютър отвори `http://localhost:8000`.

## Управление

- Стрелките или WASD движат змията; на телефон използвай бутоните под полето.
- Space поставя играта на пауза и я продължава.
- Всяка хапка носи 10 точки и ускорява змията.
- Сблъсък със стената или тялото приключва играта.
- Рекордът се запазва в браузъра, когато локалното съхранение е достъпно.

## Проверки

```sh
node --check game.js
node --test tests/game.test.cjs
```

Тестовете упражняват игровата логика с имитация на браузърната среда. За визуална проверка отвори играта в браузър.
